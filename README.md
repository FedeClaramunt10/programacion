# Programación

Ejercicios y exámenes de Python de la tecnicatura: fundamentos de programación, estructuras de datos, archivos y pandas.

## Notebooks

| Notebook | Contenido |
|----------|-----------|
| `notebooks/examenClaramuntFederico.ipynb` | Examen: programación con diccionarios y estructuras de datos. |
| `notebooks/Federico_Claramunt.ipynb` | Resolución de ejercicios de examen. |
| `notebooks/Examen_Claramunt_Federico.ipynb` | Examen en Python: manipulación de datos y lógica de programas. |

## Ejercicios (`.py`)

| Archivo | Contenido |
|---------|-----------|
| `ejercicios/3.py` … `5.5.py` | Serie de ejercicios de la materia (condicionales, bucles, funciones, listas y diccionarios). |
| `ejercicios/6.py` | Gestión de clientes y generación de facturas (archivos y formatos). |
| `ejercicios/hola.py` | Introducción a Python. |
| `ejercicios/otro.py` / `otro2.py` | Práctica: conexión y operaciones sobre bases de datos. |
| `datos/base_de_datos_clientes.txt` | Datos de clientes (anonimizados) usados por los ejercicios. |

## Temas cubiertos

- Sintaxis y tipos de datos de Python
- Control de flujo, listas, tuplas y diccionarios
- Funciones y manejo de archivos
- Introducción a pandas
- Conexión a bases de datos desde Python
